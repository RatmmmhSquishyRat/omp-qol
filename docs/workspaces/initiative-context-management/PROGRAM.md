# Program

## Goal

Give the main agent first-class, reversible, measurable control of its working context: compress/expand any range, pin/unpin any salience, and later drive pin sets through trees — without destroying the journal, without lying about native headroom, and without silently spending cache.

## Phases

### Phase 0 — Control plane (this opening)

- Workspace, invariants, workflow, refs.
- Fan-out research on current host + DCP/ACM/Pi-DCP + cache economics.
- Ingest 2026-08-09 as prior, not lock.

### Phase 1 — Host lock and seam map

- Freeze inspected OMP commit + coding-agent version in `refs/HOST-LOCK.md`.
- Map every extension hook QOL will use.
- Classify each primitive: reachable / importable / TUI-only / needs host bridge.
- Re-close or overturn the seven 17.2.12 claims in `STATUS.md`.

### Phase 2 — Shared substrate design

- Address / provenance strategy (plugin alias layer vs small host seam).
- Overlay event schema + reducer + branch replay.
- Protocol-safe range closure.
- Metrics: raw / projected / last provider / native pressure / first divergence.

### Phase 3 — Product target: C vs D

- Prototype evidence, not opinion.
- C: overlay + native seal via `session_before_compact`.
- D: trusted projection-ownership core seam.
- Keep A as baseline arm, B as diagnostic only.

### Phase 4 — Initiative compress v1

- Tools: compress / expand / state / preview; optional explicit seal.
- Self-footprint scrub in projection only.
- L1 reducer + L3 lifecycle + L5 provider-wire + L6 real-model use-through.
- Cache/cost vs native-only and overlay-only.

### Phase 5 — Initiative pin v1

- Kinds: source / snapshot / instruction.
- Default tail-zone; system explicit; mid-history experimental.
- Provider-neutral renderer.
- Compaction modes: request-only / salient / preserve.
- Behavior eval + cache/cost vs compress-only.

### Phase 6 — Pin tree

- Only after flat pin wins behaviorally.
- Definition vs active-leaf persistence split.
- March / jump / path+sibling inspect.
- Compare against manual pin baseline.

### Phase 7 — Skills / agent text

- Heuristic practice for *when* to compress/pin, never a hidden policy engine.
- Unified JSON envelope consistent with existing tools.

## Non-goals for v1

- PrimeStyle / live AGENTS self-edit.
- Marketplace / new install channel.
- Destructive journal rewrite.
- Default auto-dedup that the agent cannot see or disable.
- Frozen `@12` public syntax before provenance survives adversarial cases.
