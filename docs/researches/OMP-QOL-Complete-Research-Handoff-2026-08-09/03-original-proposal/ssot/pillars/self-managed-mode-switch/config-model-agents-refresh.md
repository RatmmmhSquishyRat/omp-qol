# 各种文件配置的运行时刷新

有一些模块本身, 例如plugin, skill, model等等是支持运行时自动刷新的;
并且一部分是用户手动调用可以刷新, 另一部分好像是OMP自行管理刷新的, 还有另外一部分将自己的刷新工具也暴露给了agent本身, 只是没有那么明显.

因此, 总体来说, OMP中的刷新机制, 不论是对于我还是对于之前使用的agents, 都是相对造成了混乱和迷惑的. 尤其是像agents自己更新model配置, 然后并没有刷新配置, 信誓旦旦地直接调用subagents, 甚至自己也没有察觉是旧的模型这种事件等等.

## 期望

因此, 在这里我们不一定要给一个统一的刷新命令或者什么, 而是要首先搞清楚各个刷新配置命令都在哪里, 应当如何使用, 以及作者为什么要这么设计, 然后再看看我们可以做什么.

其他上述没有提到的模块的配置也是如此, 需要调查. 也许我们能做什么, 或者也许暂时做不了什么.
